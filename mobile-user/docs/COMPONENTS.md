# Dokumentasi Komponen Mobile-User Beach-Go

Berikut adalah ringkasan komponen UI reusable premium yang tersedia pada aplikasi mobile:

## Komponen yang Tersedia
1. **Button**: Mendukung custom variant (primary, outline, ghost) dengan loading state.
2. **Card**: Menyediakan layout vertikal dan horizontal dengan shadow.
3. **InputText**: Input teks dengan transisi aktif focus dan penampil password.
4. **Header**: Navigasi atas otomatis yang menyesuaikan dengan history stack.
5. **LoadingSpinner**: Animasi pemuatan bawaan (inline & full overlay).
6. **Toast**: Notifikasi melayang dengan animasi fade-in otomatis.
7. **SkeletonLoader**: Efek pulse pemuatan layout data.
8. **RatingDisplay**: Visualisasi ulasan bintang dinamis.
9. **Avatar**: Penampil foto user dengan initials fallback otomatis.
10. **BottomSheet**: Panel drawer bawah responsif menggunakan `PanResponder` untuk interaksi usap (swipe-down-to-close).
